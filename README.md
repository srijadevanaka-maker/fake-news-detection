Fake News Detection Project

Overview

This project detects whether a news article is Real News or Fake News using Machine Learning and Natural Language Processing (NLP).

Technologies Used

* Python
* Pandas
* NumPy
* NLTK
* Scikit-learn
* TF-IDF Vectorizer

Dataset

Dataset used:

* Fake.csv
* True.csv

Features

* Text preprocessing
* Stopword removal
* TF-IDF vectorization
* Machine Learning model training
* Fake/Real news prediction

Project Workflow

1. Load dataset
2. Clean and preprocess text
3. Split training and testing data
4. Convert text into vectors using TF-IDF
5. Train machine learning model
6. Predict whether news is fake or real

Sample Prediction

Input:
“The Prime Minister attended an international meeting today”

Output:
Real News
